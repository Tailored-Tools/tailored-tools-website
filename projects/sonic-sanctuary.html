Sound Therapy · Maidstone, Kent

The Sonic Sanctuary

A sound therapy and sound bath practice run from a phone. One operating system handles bookings, payments, event management, customer comms, and the public website, replacing six disconnected tools that previously didn't talk to each other.

The problem

Running a one-person specialist practice on off-the-shelf tools meant Square for payments, Weebly for a website, Carrd for a landing page, Google Sheets for tracking, WhatsApp for community comms, and email for everything else. Six separate places to update. Nothing in sync. Most evenings spent reconciling what had happened during the day.

Each tool was fine on its own. The problem was the gaps between them, and the time spent gluing them together by hand.

What we built

A custom operating system, the SS OS, that hubs everything. One sign-in. One source of truth. Public events update automatically on the public website. Stripe receipts trigger WhatsApp confirmations. Customer records build themselves as people book. The phone runs the whole business; nothing else is needed day-to-day.

Event Management

Create, duplicate, edit, and retire sound bath and drum circle events. Capacity tracking. Auto-expiry. Published instantly to the public site.

Stripe Payments

Online bookings via Stripe Checkout. Receipts emailed automatically. Refunds handled inside the dashboard, no separate Stripe login needed.

Intro Pass System

First-time-visitor passes at a reduced rate. One per customer, automatically enforced via email lookup. No manual checking.

WhatsApp Integration

Automated event announcements to a 210-member sound bath community. Booking confirmations and reminders fire on schedule, no manual sends.

Customer Comms

Booking confirmations, intro pass guidance, follow-ups via email. B2B invoicing for corporate clients, separated from public event flows.

Public Website

Events page reads from the same data source as the dashboard. Real-time availability. No double-entry, no stale listings.

Tools consolidated into one operating system

The OS runs from the founder's phone. Events can be created from a venue car park, payments verified between client sessions, and announcements scheduled while putting the kids to bed. The point isn't volume; it's removing the friction that quietly costs a one-person practice its evenings.

About the business

The Sonic Sanctuary is a Maidstone-based sound therapy and sound bath practice. Public events run monthly at venues across Kent; private sessions and corporate bookings handled separately. The OS is intentionally invisible to attendees, customers see a clean public site, a smooth checkout, and the right reminders at the right time.

Founded and run by James Edwards, who also built Tailored Tools. Because The Sonic Sanctuary is the founder's own practice, the platform is in daily use by the person who built it. Anything that breaks gets fixed; anything that's awkward gets reshaped. It's the slowest-moving but most lived-in of the platforms we ship.
